Run it once for each of the three frozen stage-0 worlds: 6839fb8f (GT), b2a75ab4 (control), and da4ac2d3 (walk 5). Use a fresh output directory for each world. The source is a read-only, already finished world directory whose `solve/<session>/solution.json` says `solve.matching: frozen` and whose named database exists. The b2a75ab4 seed-20 source in STAGE0.md is unsuitable; use its prepared seed-0 frozen copy. Never point it at the live Tower store.

The lead supplies the `--source-world`, `--session`, and fresh `--out` paths. Invoke the script through `lead/gpulock.py run --who W0-1 --what "C18 W0-1 identity <world>" -- <venv-python> <this-script> ...`. Pass `--full-refinish`, `--env-file <RUN>/experiments/C22-REPLAY/switches/walk5.env`, and `--compare-w0 <RUN>/experiments/W0-STAGE0/compare_w0.py`. Set the stage-0 source/capture environment used to produce each frozen input before launching. The runner forces consensus 3, stage timing on, and the W0-1 switch per arm. It enables deterministic appearance gains only when that switch exists in the code under test; otherwise appearance and cache provenance are declared by-design differences. It does not cap threads in the parent, so P4 keeps its old DINOv2 thread count.

Example argument shape:

```text
<venv-python> scratch/w0-1-proof/prove_identity.py --source-world <frozen-copy>/worlds/<world-id> --session <session-id> --out <fresh-work-directory>/w0-1-<world-id> --seed 0 --full-refinish --env-file <RUN>/experiments/C22-REPLAY/switches/walk5.env --compare-w0 <RUN>/experiments/W0-STAGE0/compare_w0.py
```

The direct phase makes six copies and maps further seeds 1 and 2 three times per arm. It compares every `Solution` field except `solved_at` and `timing`, including every pose and the exact dtype, shape, and bytes of every array. It checks the source database before and after, requires the concurrent event with no fallback, and requires private scratch to be swept. The product mapper checks each private database before and after the child runs.

The full phase makes six more independent copies, omitting copied `verify_pairs` caches so P4 descriptors and similarities are recomputed at the original thread count. A proof-only `sitecustomize.py` wrapper dumps **every** `_map_candidate` result from inside each finalize process and draw child, including unchosen draws. The runner compares those dumps old x3 versus new x3, asserts from I0 that every new run took `after-draw-0` with no fallback, and compares the five other published worlds to old run 1 with the C18 `compare_w0.py` spec. It adds one in-memory exclusion for `consensus_concurrent`; the external comparator file stays unchanged. It also compares **all** P4 `pairs.npz` arrays, including `similarity`, across all six runs. No new published keys are allowed.

Before every concurrent run the runner checks free RAM against the declared child budget. `measure_commit.py` is the separate CPU-only walk-size peak-commit probe. Give it the scored walk-5 world under `physical-test/scored/da4ac2d3/worlds/`, its session ID, and a fresh output under this worktree's `.w01f-scratch/`. It copies the world, launches one real child, writes `commit_probe.json`, and leaves the copy in place. Set `CUDA_VISIBLE_DEVICES=-1`. It has not been run here.

`result.json` and `VERDICT IDENTICAL` mean all scripted assertions passed. The individual `compare-old-1-vs-*.txt` files end in `VERDICT IDENTICAL`; read them and the JSON reports for detail. A nonzero exit or `VERDICT DIFFERS` fails the proof. Keep the output directory; the runner refuses to overwrite it. The existing serial mapper removes its own transient sparse models inside each copied world. After this proof, the lead still runs the separate C22 quiet replay timing and live-safety proof. A pass on these frozen worlds establishes identity only for their inputs, host, and pinned stack.
